🚀 Публикация на GitHub Pages

Публикует ТЕКУЩУЮ страницу (со всеми данными, которые в неё уже загружены) как index.html в вашем репозитории — без git, без скачивания файла вручную. Через 30–60 сек GitHub Pages обновит сайт по той же ссылке.
⚠️ Нужен GitHub-токен с правом записи. Создайте fine-grained personal access token (github.com → Settings → Developer settings → Fine-grained tokens) с доступом ТОЛЬКО к этому одному репозиторию и правом Contents: Read and write, с сроком действия (например 90 дней). Токен хранится только в этом браузере (localStorage), никуда больше не отправляется, кроме api.github.com.

⏰ Время автоотправки отчёта

📝 Заметки к блокам сводки

▸ показать
Сводка группирует риск-лоты по виду транспорта и точке (Турция / Алят и т.д.). Когда среди риск-лотов появляется новое направление или точка (например, новый «остаток в Аляте»), строка для него добавляется в этот список автоматически — заводить её вручную не нужно. Здесь можно добавить одну строку статуса на каждый такой блок — она попадёт в сообщение как «Статус: …» под итогом по контейнерам.
